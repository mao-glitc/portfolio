# portfolio

宮崎真生（大和大学 情報学部 2年）のポートフォリオサイトです。

**公開中のページ：https://mao-miyazaki.pages.dev**

手で書くのはプロフィールの JSON だけです。各プロジェクトの「コードの行数・テスト数・コミット数・最終更新日」は、ビルドするたびにソースコード本体から数えています。

## なぜこの作りにしたか

| 決めたこと | 理由 |
|---|---|
| 数値を手で書かず、ビルド時に実物から数える | 実績を盛れない作りにしたかった。ポートフォリオの数値が古くなったり、誇張されたりするのを防ぐ |
| 外部パッケージなし（Node.js の標準ライブラリだけ） | 1枚の HTML を作るだけなので、依存を増やす理由がない。何年後でも同じようにビルドできる |
| 出力は CSS を埋め込んだ HTML 1枚 | ホスティング先を選ばない。Webフォント以外の外部読み込みがない |
| 手元でビルドしてから Cloudflare Pages にアップロード | 集計対象のプロジェクトは隣のフォルダにあり、このリポジトリには含まれていない。そのため、GitHub と連携した自動ビルドでは数えられない |
| デザインはデジタル庁デザインシステム（DADS）に準拠 | 読みやすさとアクセシビリティの基準が公開されているから。状態のラベルも、色だけでなく必ず文字を添えている |

## 仕組み

```
profile.json ──────────────┐
                           ├─ build.mjs ─→ render.mjs ─→ dist/index.html ─→ Cloudflare Pages
../各プロジェクト（実物）──┘   （集計）      （HTML生成）
```

- `profile.json`：手で書く情報（自己紹介・受賞・経験・プロジェクトの説明）。プロジェクトに `path` を書くと、そのフォルダが集計の対象になる
- `build.mjs`：各プロジェクトを走査して、行数・テスト数・コミット数・最終更新日を集計する。`metrics` を書くと、JSON から任意の数値（例：収集件数）も取り出せる
- `render.mjs`：プロフィールと集計結果から HTML を生成する。ほかのツールからも使えるよう、描画だけを分けている
- `dads.css`：DADS の公式トークンを転記したスタイル

## 使い方

```bash
npm install        # wrangler（デプロイ用）だけが入る
npm run build      # dist/index.html を生成
npm run deploy     # ビルドして Cloudflare Pages に公開
```

`path` に書いたフォルダが手元にない場合、そのプロジェクトは数値なしで表示されます（ビルドは止まりません）。

## 技術

Node.js（標準ライブラリのみ）／ Cloudflare Pages ／ wrangler ／ Claude Code を使って開発
